# NEW CITY — CRM Imobiliário

O NEW CITY é uma aplicação web desenvolvida no Bubble para a EXPO TECH da UniFECAF. O projeto ajuda profissionais do setor imobiliário a organizar sua carteira de clientes e manter os dados de contato atualizados.

Após criar uma conta e entrar no sistema, o usuário pode cadastrar um cliente com nome, e-mail e telefone. Na carteira de clientes, pode pesquisar pelo nome, consultar a data de cadastro e editar os dados de contato. A tela exibe tanto o total de clientes cadastrados quanto a quantidade de resultados da busca.
